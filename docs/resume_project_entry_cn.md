# 简历项目经历建议

## Duolingo 增长与营销运营分析 | Tableau · SQL · Python

- 基于 Duolingo **12 个季度**官方披露（2023 Q1-2025 Q4），分析用户规模扩张是否伴随更强的活跃和商业化表现；以 2026 年 2-3 月竞品快照补充有限背景。
- 识别 DAU 增长 **160%**、MAU 增长 **83%**，DAU/MAU 从 **28.0% 提升至 39.6%（+11.6 个百分点）**；在用户规模增速放缓的背景下，明确活跃与商业化的复盘重点。
- 完成并发布**两页 Tableau Dashboard** 与双语案例，明确三项运营优先事项：**保护活跃质量、强化会员价值沟通、兼顾增长与用户自主控制**；拟议复盘与测试以内部证据和免费体验保护指标为前提。
